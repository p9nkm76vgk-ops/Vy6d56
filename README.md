# Entreno OS

App personal de entrenamiento en casa: plan automático por bloques, modo entreno guiado por voz con tempo exacto, figuras animadas, yoga, pilates y sesiones atléticas, disposición diaria, récords y test de atleta.

## Instalar en el iPhone o el iPad
1. Abre la web de la app en **Safari**.
2. Toca **Compartir** → **Añadir a pantalla de inicio**.
3. Ábrela desde el icono: se ve a pantalla completa y funciona sin conexión.

Los datos se guardan en el dispositivo. Para pasarlos a otro: *Plan → Tus datos → Copiar copia de seguridad* y, en el otro dispositivo, *Restaurar copia*.
